Molten Core

Molten CoreWoW Forever Downgrader

Install the version of WoW Forever you need in a separate folder.

Download for Windows x64 Requires Microsoft Edge WebView2 Runtime.
Download Flatpak for Linux x64 The first installation may download the GNOME runtime from Flathub.

How to use it

  1. Close WoW and Battle.net.
  2. Select your up-to-date Battle.net installation and a separate destination folder.
  3. Enter the full target version. Validate it, then install. Find the copy in the destination’s _forever_ folder.
