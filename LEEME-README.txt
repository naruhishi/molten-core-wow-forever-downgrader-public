Molten Core - WoW Forever Downgrader | Windows x64

Español
Requiere Microsoft Edge WebView2 Runtime. Cierra WoW y Battle.net. Abre Molten-Core-WoW-Forever-Downgrader.exe y escribe la versión completa
que necesitas, por ejemplo 1.60.1.71037. Pulsa Validar para
comprobar los manifiestos sin instalar. Selecciona el WoW Forever de origen
y un destino separado con espacio suficiente. Instalar vuelve a comprobar
la versión. Al terminar, encuentra el cliente en _forever_ en la carpeta nueva.
Si cancelas, usa las mismas carpetas y versión para reanudar.

English
Requires Microsoft Edge WebView2 Runtime. Close WoW and Battle.net. Open Molten-Core-WoW-Forever-Downgrader.exe and enter the full build
you need, for example 1.60.1.71037. Select Validate to
check manifests without installing. Select the existing WoW Forever copy
and a separate destination with enough space. Install checks the build again.
When finished, select the new _forever_ folder in the destination.
After cancellation, use the same folders and version to resume.
